# Healthcare Analytics Dashboard | Power BI

## Project Overview

An interactive Healthcare Analytics Dashboard developed using Microsoft Power BI to analyze hospital operations, patient demographics, admissions, medical conditions, and financial performance.

The dashboard provides insights into healthcare performance through interactive visualizations, KPI cards, and filters.

## Dashboard Preview

![Healthcare Analytics Dashboard](Dashboard/Healthcare%20Analytics%20Dashboard%20Overview.png)

## Dashboard Pages

### 1. Overview
- Total Revenue
- Total Admissions
- Total Hospitals
- Total Doctors
- Patient distribution by insurance provider and medical condition
- Admission trends
- Top 5 doctors by revenue and patients

### 2. Financial Analysis
- Revenue and admission KPIs
- Patient distribution by blood type and medical condition
- Insurance provider analysis
- Medication analysis
- Gender, admission type, test results, and age distribution
- Admission trend analysis

## Technology Stack

- Microsoft Power BI Desktop
- Power Query
- DAX
- CSV Dataset
- GitHub

## Data Model

The project currently uses a single-table data model named `healthcare_dataset`, containing patient, hospital, admission, medical, insurance, and billing information.

## Repository Structure

- `Dashboard/` – Power BI report and dashboard previews
- `Dataset/` – Source dataset and data dictionary
- `DAX/` – DAX documentation
- `Documentation/` – Business requirements, data model, and business insights

## Project Objectives

- Monitor healthcare operational performance.
- Analyze patient admission patterns.
- Understand revenue distribution.
- Evaluate hospital, doctor, and insurance provider performance.
- Support data-driven healthcare decisions.
